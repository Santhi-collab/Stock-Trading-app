# SB Stocks

A full-stack paper-trading simulator built on the MERN stack (MongoDB, Express, React, Node) with Redux Toolkit for state and Chart.js for candlestick charting. Practice buying and selling US-listed stocks with $100,000 in virtual cash, live-ish market data, and full order/wallet ledgers — zero financial risk.

Pages : Login/Register → Home (Trending + Watchlist) → Stock chart with quick Buy/Sell → Portfolio → My Orders (History) → My Account (wallet) → Admin (Home / Users / Orders / Transactions).

## Folder structure

```
sb-stocks/
├── server/     Express + MongoDB API
└── client/     React + Vite + Tailwind + Redux Toolkit frontend
```

## 1. Requirements

- Node.js v18+ and npm
- MongoDB running locally (or an Atlas connection string)

## 2. Backend setup

```bash
cd server
npm install
cp .env.example .env
```

Open `.env` and set:
- `MONGO_URI` — your MongoDB connection string
- `JWT_SECRET` — any long random string
- `FINNHUB_API_KEY` — optional. Geting a free key at https://finnhub.io/ for real
  live quotes. **Leaved it blank and the app still works** — it automatically
  falls back to a realistic simulated OHLC feed, so we can develop and demo
  without signing up for anything.

Seed the database with 22 starter stocks and a demo admin account:

```bash
node seed.js
```

This prints a demo admin login (`admin@sbstocks.demo` / `Admin@123`).

Start the API:

```bash
npm run dev    # with nodemon, auto-restarts on changes
# or
npm start
```

The API runs on `http://localhost:5000` by default.

## 3. Frontend setup

In a second terminal:

```bash
cd client
npm install
cp .env.example .env   # only needed if our API isn't on localhost:5000
npm run dev
```

Open `http://localhost:5173`. Register a new account (starts with $100,000
virtual cash and a default portfolio created automatically) or log in as the
seeded admin.

## 4. Pages 

- **Login / Register** — public landing with hero + auth forms (Username, Email, Password, User type)
- **Home** — "Trending stocks" + **My Watchlist** (our saved stocks, add/remove) + a search panel to find and add any listed stock
- **Stock chart** — candlestick chart (Chart.js + `chartjs-chart-financial`) with a Buy/Sell toggle, quantity, computed total, and a single execute button
- **Portfolio** — current holdings: exchange badge, symbol, quantity, price, total value, P&L, `View Chart`
- **History ("My Orders")** — every buy/sell this user placed, with order status
- **Profile ("My Account")** — trading balance, **Add Funds** / **Withdraw** (with payment mode), and the wallet transaction ledger below
- **Admin: Home** — quick stats overview
- **Admin: Users** — user id, username, email, balance
- **Admin: Orders** — every stock trade across all users
- **Admin: Transactions** — every wallet deposit/withdrawal across all users

## 5. Tech stack

- **Backend**: Express, Mongoose/MongoDB, JWT auth (bcrypt), a simulated/live market-data layer
- **Frontend**: React, Vite, Tailwind, **Redux Toolkit** (`store/authSlice.js` holds the logged-in user), **Chart.js** with `chartjs-chart-financial` for candlesticks, react-router-dom, react-toastify

## 6. Backend structure

- `config/db.js` — MongoDB connection
- `models/` — `userModel`, `stockSchema`, `orderSchema` (holdings), `transactionModel` (stock buy/sell log), `portfolioModel`, `walletTransactionModel`, `watchlistModel`
- `controllers/` — user auth/profile, stock listing/search, buy/sell logic, portfolio, wallet (deposit/withdraw), watchlist, portfolio management
- `middleware/authMiddleware.js` — JWT auth (`protect`) + `adminOnly` guard
- `routes/` — REST endpoints for users, stocks, orders (portfolio), transactions (stock trades), wallet, portfolios, watchlist
- `utils/marketData.js` — live Finnhub quotes with an automatic simulated OHLC fallback
- `seed.js` — starter stock list + demo admin + default portfolio

## 7. Key concepts

- **Orders vs. Transactions**: "Orders" = individual stock buy/sell trades (My Orders page, admin Orders page). "Transactions" = wallet deposit/withdraw activity (My Account, admin Transactions page). Kept as separate ledgers, matching the reference app.
- **Portfolio**: every user gets one default portfolio ("Main") automatically at registration — buy/sell just works, no setup needed.
- **Watchlist**: a real personal list — search any listed stock and tap "+ Watchlist" to save it; remove it any time. Separate from the general stock browser.
- **Market data**: `FINNHUB_API_KEY` is optional. Without it, quotes and candlestick history are generated by a deterministic simulator per symbol.
